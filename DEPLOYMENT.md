# GitHub Pages Deployment Guide

## Quick Start

### 1. Push to GitHub

```bash
# Initialize git (if not already done)
git init
git add .
git commit -m "Initial commit: Salary Calculator PWA"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/salary-calc.git
git push -u origin main
```

### 2. Enable GitHub Pages

1. Go to **Settings** → **Pages**
2. Under "Build and deployment":
   - **Source**: Select "Deploy from a branch"
   - **Branch**: Select `main` and `/root` folder
   - Click **Save**

3. Wait 1-2 minutes for GitHub Pages to build and deploy
4. Your site will be available at: `https://YOUR_USERNAME.github.io/salary-calc`

## PWA Installation from GitHub Pages

The app works as a Progressive Web App from GitHub Pages:

### iOS (Safari)
1. Open `https://YOUR_USERNAME.github.io/salary-calc` in Safari
2. Tap **Share** → **Add to Home Screen**
3. App is now installed and works offline!

### Android (Chrome)
1. Open `https://YOUR_USERNAME.github.io/salary-calc` in Chrome
2. Tap **Menu** → **Install app** (or **Add to Home Screen**)
3. App is now installed and works offline!

### Desktop (Chrome/Edge)
1. Open `https://YOUR_USERNAME.github.io/salary-calc`
2. Click install icon in address bar (if shown)
3. Works as standalone app window

## Troubleshooting

### Issue: App loads but styles don't work
**Solution**: Clear browser cache and hard refresh (Ctrl+Shift+R or Cmd+Shift+R)

### Issue: Service Worker errors
**Solution**: Check browser console for SW errors. The app works offline but SW registration may fail behind some proxies.

### Issue: PWA installation doesn't show
**Solution**: 
- Use HTTPS (GitHub Pages uses HTTPS by default ✓)
- Check that `manifest.json` is valid
- Try on a different browser

### Issue: Data not persisting
**Solution**: IndexedDB requires secure context (HTTPS). GitHub Pages provides this by default.

## Custom Domain Setup

To use your own domain instead of github.io:

1. In **Settings** → **Pages**
2. Under "Custom domain", enter your domain
3. Add DNS records to your domain registrar:
   ```
   CNAME → username.github.io
   ```
4. GitHub will verify and enable HTTPS

## Performance Notes

- **Initial Load**: ~2-3 seconds (first time with no cache)
- **Cached Load**: <1 second (with Service Worker)
- **Bundle Size**: ~50KB total (HTML + CSS + JS)
- **Database**: Limited by browser (typically 5-50MB)
